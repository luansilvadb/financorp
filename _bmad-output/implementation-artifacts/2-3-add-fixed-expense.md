# Story 2.3: Add Fixed Expense via Bottom Sheet

## User Story

As a resident,
I want to add a fixed monthly expense through a bottom sheet form,
So that I can quickly register bills to be split with the house.

## Acceptance Criteria

**Given** I'm on the home screen
**When** I tap the FAB and select "Despesa Fixa"
**Then** a bottom sheet opens at 60% height with fields: nome, valor (R$ mask), dia_vencimento

**Given** the form is open
**When** I type a value
**Then** the preview updates in real time: "R$ X ÷ 3 = R$ Y/cada"

**Given** the form is valid
**When** I tap "Salvar"
**Then** the StampAnimation plays (scale 0→1.4→1.0, haptic feedback)

**And** the expense appears in the list immediately (optimistic update)
**And** the bottom sheet closes

**Given** I try to close the sheet with unsaved data
**When** I pull down or tap backdrop
**Then** a confirmation appears: "Dados não salvos. Fechar mesmo?"

**And** validation appears inline below fields with 500ms debounce (not while typing)

## Technical Requirements

### Bottom Sheet Pattern (UX-DR7)

From UX Design Spec:

- Height: 60% of screen, radius top 20px
- Handle bar: 36×4px, color #D4D2CC
- Padding: 20px 24px 32px
- Primary button fixed at bottom above safe area
- Backdrop rgba(0,0,0,0.3), touch closes with confirmation if unsaved data

### Form Fields

| Field              | Type                    | Validation           | Default |
| ------------------ | ----------------------- | -------------------- | ------- |
| **Nome**           | Text input              | Required, min 1 char | ""      |
| **Valor**          | Text input with R$ mask | Required, > 0        | ""      |
| **Dia vencimento** | Number input (1-31)     | Required, 1-31       | ""      |

### Optimistic Add Flow

```dart
// On save tap:
final newDespesa = Despesa(
  id: null, // will be generated by Supabase
  nome: nomeController.text,
  diaVencimento: int.parse(diaController.text),
  valor: double.parse(valorRaw),
);

await ref.read(despesasProvider.notifier).optimisticAdd(
  (state) => [...state, newDespesa],
  () => ref.read(repositoryProvider).createDespesa(newDespesa),
);

// Then show StampAnimation and close sheet
```

### Stamp Animation (UX-DR4)

```dart
// After successful add:
StampAnimation.trigger(context);
// 300ms: scale 0→1.4→1.0, haptic mediumImpact, bounce, glow
```

### Inline Validation (UX-DR10)

```dart
// Validation on onChanged with 500ms debounce:
_timer?.cancel();
_timer = Timer(const Duration(milliseconds: 500), () {
  if (nomeController.text.isEmpty) {
    _errors['nome'] = 'Nome é obrigatório';
  } else {
    _errors.remove('nome');
  }
  setState(() {});
});
```

Error display:

- Border changes to rust `#C2654A` at 60% opacity
- Error text below field in 12px rust color
- ⚠ icon before error text
- No modal dialogs for validation

## Dev Notes

- The existing `SpikeModalSheet` at `lib/features/finance/views/widgets/spike_modal_sheet.dart` currently handles BOTH fixed expenses and card purchases. The cleanest approach is to either:
  1. **Refactor SpikeModalSheet** to delegate to dedicated sheets (AddExpenseSheet, AddPurchaseSheet)
  2. **Replace SpikeModalSheet entirely** with the new sheets and update FAB to open AddExpenseSheet directly

  Option 1 is preferred — it preserves existing code while adding the new dedicated form.

- The `Divi` app already has a currency formatter in `lib/core/utils/formatters.dart`. Check if it supports input masking. If not, implement a simple BRL mask using `TextInputFormatter`.

- The optimistic add should use a temporary ID (null or UUID) for the local state. The real ID is generated by Supabase on insert. After the server responds, the list will be refreshed with the real data.

- The StampAnimation may not exist as a standalone widget yet. If it doesn't, create a simple version that shows a checkmark with scale animation and haptic feedback. The full 6-frame animation (from UX spec) can be refined in a later story.

- The real-time preview should use `TextEditingController` listeners on the valor field to update the calculated division on every keystroke.
