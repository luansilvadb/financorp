# 🛡️ Acordos de Trabalho (DoR & DoD)

Este documento define os padrões de qualidade inegociáveis para a **Mente Brilhante Ω** no projeto **DIVI**.

## 🚀 Definition of Ready (DoR)
*Uma história só entra na Sprint se:*
- [ ] O valor de negócio está claro ("Para que...").
- [ ] Os critérios de aceite estão definidos via BDD.
- [ ] A dependência técnica foi mapeada (ex: Tabelas no Supabase).
- [ ] O esforço foi estimado (T-shirt size).

## ✅ Definition of Done (DoD)
*Uma história só é considerada pronta se:*
- [ ] Código segue o padrão modular e Motor O(N).
- [ ] Não há débitos técnicos óbvios (Linter Passing).
- [ ] Testes automatizados (Unit/Widget) cobrem o novo fluxo.
- [ ] Optimistic UI implementado para mutações.
- [ ] Documentação técnica (`spec/`) atualizada.

---
*Sem conformidade com estes padrões, o incremento de software é rejeitado.*
