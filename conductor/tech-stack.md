# Technology Stack

## Frontend
- **Framework**: Flutter (Dart)
  - Cross-platform mobile/web app framework
  - Hot reload for rapid development
  - Dart for type safety and performance
  - Flutter Navigator 2.0 for routing
- **State Management**: Flutter Riverpod
  - Lightweight, reactive state management
  - Type-safe with compile-time checks
  - DevTools support for debugging
- **UI Library**: forui.dev
  - Exclusive UI component library for all UI needs
  - Touch-optimized components for mobile
  - Consistent design system with neutral theme
  - Lucide icons integration (via forui_assets)
- **Additional UI**: Phosphor Icons
  - Multiple icon weights (Bold, Light, Thin, Fill, Duotone)
  - Consistent icon system across the app
- **Build Tool**: Flutter build system
  - Hot reload during development
  - Optimized production builds for mobile and web
  - Font tree-shaking for reduced bundle size

## Web & Platform Support
- **Web Deployment**: Flutter Web (CanvasKit renderer)
  - Service worker generated by Flutter build
  - Web app manifest (manifest.json) for PWA-like features
  - Single-page application architecture
- **App Shell**: Flutter MaterialApp widget
  - Instant loading on repeat visits
  - Built-in navigation and routing
  - Theme management via forui.dev

## Backend Integration
- **BaaS**: Supabase
  - PostgreSQL database via Supabase client
  - Authentication (GoTrue client)
  - Real-time subscriptions
  - Storage and edge functions
- **API Client**: Supabase Flutter SDK
  - Type-safe queries with Dart
  - Built-in authentication management
  - Real-time data synchronization

## Hosting & Deployment
- **Platform**: Supabase Hosting or custom server
  - Automatic HTTPS
  - Flutter web build deployed as static files
  - Supabase handles backend infrastructure
- **CI/CD**: GitHub Actions
  - Automated testing on pull requests
  - Flutter build and deploy on merge to main
  - Performance monitoring via Flutter devtools

## Testing
- **Unit/Integration**: Flutter test framework
  - Widget testing for UI components
  - Integration testing for user flows
  - Code coverage reporting
- **E2E Testing**: Flutter integration_test package
  - Cross-platform automation (mobile & web)
  - Test critical user flows
- **Performance**: Flutter devtools & web performance tools
  - Bundle size analysis via flutter build
  - Performance profiling in devtools
  - Font tree-shaking optimization verification

## Development Tools
- **Linting/Formatting**: Flutter analyzer + dart format
  - Consistent code style across the team
  - Pre-commit hooks with husky or similar
  - flutter_lints package for best practices
- **Code Generation**: build_runner
  - freezed for immutable data classes
  - json_serializable for JSON serialization
- **Version Control**: Git + GitHub
  - Trunk-based development or GitFlow
  - Pull request templates and code review requirements
- **Package Manager**: pub (dart pub)
  - Flutter package ecosystem
  - forui.dev as primary UI library

## Monitoring & Analytics
- **Error Tracking**: Sentry (Flutter SDK)
  - Real-time error reporting
  - User session replay for debugging
- **Analytics**: Supabase analytics or custom tracking
  - User behavior tracking
  - Feature usage metrics
- **Performance Monitoring**: Flutter performance tools
  - Frame rendering time tracking
  - Memory usage monitoring
  - Network request profiling
